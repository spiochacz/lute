# gen-atom-vectors

Generates the expected results for the TypeScript port of `html/atom` (`ts/src/html/atom`):

- `ts/src/html/atom/testdata/atom_vectors.json`: the 368 atom constants (name, value, `String()`), `hash0`, `maxAtomLen`, the 512-slot hash table and `atomText` (parsed from `html/atom/table.go` with `go/parser`), `atom.Lookup` results (atom texts, upper-case forms, one-edit variants, other byte strings) and `atom.String` results.

Every expected value comes from the real Go package (`github.com/88250/lute/html/atom`). The inputs come from a fixed PCG seed, so the output is reproducible. Invalid UTF-8 inputs are included.

Files:

- `main.go`: the generator.
- `names_gen.go`: generated by `convert-table.mjs`. It references every atom constant through the real package, so a missing name fails to compile.
- `convert-table.mjs`: one-off converter, run once to write `ts/src/html/atom/table.ts` and `names_gen.go` from `html/atom/table.go` (no value is retyped by hand). Run it again only if `table.go` changes: `node tools/gen-atom-vectors/convert-table.mjs` from `ts/`.
- `go.mod`: its own module (`lute-ts-gen-atom-vectors`) with `replace github.com/88250/lute => ../../..`, so the repo's root `go.mod` and `go.sum` are not changed.

## Regenerate

From `ts/tools/gen-atom-vectors` (Git Bash):

```sh
export GOTOOLCHAIN=local
"/c/Program Files/Go/bin/go.exe" run -tags javascript . > ../../src/html/atom/testdata/atom_vectors.json
```

Then run the tests from `ts/`:

```sh
node --test src/html/atom/atom.vectors.test.ts
```
